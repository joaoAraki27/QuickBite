## QuickBite 🍔

QuickBite is an online menu system that allows customers to place orders directly via Line or WhatsApp.
Users can sign up, create their own accounts, and store custom menus linked to each account for easy access and management.

## Features

- User registration and authentication

- Personalized menu storage for each user account

- Intuitive and responsive interface

## Technologies Used

```text
Front-end: React, Next.js, TypeScript
Back-end: Node.js, Express, TypeScript
Database: PostgreSQL
Authentication: JWT or custom system
```

## Setup Instructions
1) Server Setup

Navigate to the server directory:

```
cd server
```
Create or edit the .env.local file with your environment variables:
```
DB_USER=your_username  
DB_PASSWORD=your_password  
DB_NAME=quickbite
```

Build the server:
```
npm run build
```

2) Website Setup

Navigate to the website directory:
```
cd website
```
Install dependencies:
```
npm install
```

3) Run the Project
```
npm start
```
After configuring both server and website, your QuickBite app is ready to launch.
Users can sign up, create menus, and start receiving orders through Line or WhatsApp.
